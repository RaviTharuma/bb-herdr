Run BB process hosts in Herdr panes while preserving BB native provider and plugin contracts.

## What you get

- Supervised process trees with reliable cancellation and cleanup.
- Private, authenticated local transport between BB and each hosted process.
- Herdr socket discovery that follows the running server configuration.
- Native support for macOS arm64 and Linux x64.

The plugin keeps orchestration local. It does not replace BB providers or modify production BB configuration.
